# DS2 Trainer Hotkeys

| Key | Action |
|-----|--------|
| F1  | Infinite chiral bandwidth |
| F2  | Lock stamina at max |
| F3  | Toggle zero cargo weight |
| F4  | Freeze BB stress meter |
| F5  | Clear timefall timer |
| F10 | Quit overlay |

Hotkeys are configurable in `ds2_trainer/config/profiles/default.toml`.
